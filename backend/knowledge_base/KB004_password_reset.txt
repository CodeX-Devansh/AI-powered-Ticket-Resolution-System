Article ID: KB004
Title: Corporate Password Reset
Category: Account
Subcategory: Password Reset

Problem:
An employee has forgotten the corporate password.

Troubleshooting Steps:
1. Open the approved corporate password-reset portal.
2. Enter the employee ID.
3. Complete the required identity verification.
4. Create a new password that meets the password policy.
5. Sign in again using the new password.

Resolution:
The employee should be able to authenticate with the new password.

Escalation:
If identity verification or password reset fails, escalate to Identity and Access Management.

Priority Guidance:
Medium.

Keywords:
password, reset password, forgotten password, credentials
